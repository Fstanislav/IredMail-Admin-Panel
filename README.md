# Проект управления пользователями и почтовыми сообщениями

Этот проект представляет собой веб-приложение для управления пользователями и почтовыми сообщениями, интегрированное с IredMail. Приложение позволяет администраторам создавать и управлять пользователями, а также просматривать статистику почтовых сообщений.

## Возможности

- Создание и управление пользователями
- Просмотр статистики пользователей и почтовых сообщений
- Интеграция с IredMail для управления почтовыми ящиками
- Настройка администратора и параметров подключения к базе данных через страницу установки

## Требования

- Веб-сервер (например, Apache или Nginx)
- PHP 7.4 или выше
- MySQL или MariaDB
- IredMail установленный и настроенный

## Установка

### Шаг 1: Клонирование репозитория

Клонируйте репозиторий на ваш сервер:

```sh
git clone https://github.com/yourusername/yourproject.git
cd yourproject
```

### Шаг 2: Настройка веб-сервера

#### Apache

Создайте файл конфигурации виртуального хоста:

```sh
sudo nano /etc/apache2/sites-available/yourproject.conf
```

Добавьте следующую конфигурацию:

```apache
<VirtualHost *:80>
    ServerAdmin admin@yourdomain.com
    ServerName yourdomain.com
    DocumentRoot /var/www/yourproject

    <Directory /var/www/yourproject>
        Options Indexes FollowSymLinks
        AllowOverride All
        Require all granted
    </Directory>

    ErrorLog ${APACHE_LOG_DIR}/yourproject_error.log
    CustomLog ${APACHE_LOG_DIR}/yourproject_access.log combined
</VirtualHost>
```

Активируйте виртуальный хост и перезапустите Apache:

```sh
sudo a2ensite yourproject.conf
sudo systemctl restart apache2
```

### Шаг 3: Настройка базы данных

Создайте базу данных и пользователя для вашего проекта:

```sql
CREATE DATABASE yourdatabase;
CREATE USER 'youruser'@'localhost' IDENTIFIED BY 'yourpassword';
GRANT ALL PRIVILEGES ON yourdatabase.* TO 'youruser'@'localhost';
FLUSH PRIVILEGES;
```

### Шаг 4: Настройка проекта

Перейдите в браузере по адресу `http://yourdomain.com/setup.php` и заполните форму для настройки администратора и параметров подключения к базе данных.

### Шаг 5: Завершение установки

После завершения настройки вы будете перенаправлены на страницу входа. Войдите с использованием учетных данных администратора, указанных на странице настройки.

## Использование

### Вход

Перейдите по адресу `http://yourdomain.com/login.php` и войдите с использованием учетных данных администратора.

### Управление пользователями

После входа вы сможете создавать и управлять пользователями, а также просматривать статистику почтовых сообщений.
